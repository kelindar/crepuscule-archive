-1-Désinstalle complêtement tout Uo.
-2-Installe Uo Ml sans faire la mise a jours.
-3-Le dossier portera le nom -EAgame.
-4-Dans program file fait un dossier portant le nom de...Peu importe le nom en faite^^
-5-Ensuite , load le fichier crépuscule proposer sur le site dans le dossier hors UO Ml (voir -4-)
-6-Clique sur le dossier de crépuscule (voir-5-) et fait la mise a jours de crépuscule.
-Lorsque se sera fait retourne dans le dossier UO Ml et cherche l'icone de Uo de base , l'un devrai porter le nom de crépuscule.exe
-7- Clique dessus et crépuscule devrai se lancer.
