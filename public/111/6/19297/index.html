Post by Feydanith, dit la Carpe - February 4, 2008 at 8:25 PM

Amusant, j'avais pas prévu ce bug.

C'est parce que les objets du port sont fabriqués à partir d'autres items dont on change l'item ID ( l'apparence quoi ). Cependant, d'un point de vu fonctionnel, dans le serveur, ça reste une entité "étagère de base" et quand tu la tournes, ben ça se raccroche à la fonction pour tourner de l'étagère de base, donc ça met le skin de l'étage de base tournée ^^

Pour résoudre ça, il faudrait coder toutes les étagères avec les différents items id ou trouver une astuce avec le flip' attribute pour qu'il aille lire un tableau de correspondance.

Conclusion : Ne faites surtout pas tourner vos objets du port sans la présence d'un gm pour récupérer le coup
