Crépuscule a changé d'herbergeur.

Notre nouvelle adresse Ip : LoginServer=crepuscule.darconet.be,2593.

Pour modifier l'adresse, vous allez dans le dossier où se trouve installé votre version d'Uo Crepuscule.
Cercher le ficher nommé "Login", vous l'ouvrez avec le bloc-note et vous modifier le texte :

Citation:
;Loginservers for Ultima Online
LoginServer=crepuscule.darconet.be,2593

Ceci vous fait vous enregistrez le fichier. Vous pouvez lancer à présent crépuscule normalement.
