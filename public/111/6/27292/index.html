Post by Phydias Shaytan, CP - February 19, 2009 at 11:23 PM

Pour les mêmes raisons que vous ne lootez pas de colliers ni de boucles d'oreilles magiques, ceux-ci n'héritent pas de la bonne classe dans les scripts. Dès que ça sera changé, ça fonctionnera ^^

Le plus simple pour éviter les pertes consiste à garder les anciens scripts de bijoux, de dans modifier le deserialize pour transférer les propriétés de l'ancien bijoux vers le nouveau puis de supprimer l'ancien.

Pour le nouveau, je crois que la classe dont ça doit hériter est BaseJewel.
