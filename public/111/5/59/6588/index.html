Utilisation du formulaire

Post by Ex-Mélodie - April 23, 2006 at 11:37 PM

Catégorie : Bouton general dans le menu du crafteur, donnant acces a la liste d'objet
Nom de l’item : Nom de l'objet en question ( nom du bouton donc )
Skin ( ID ) de l’item : 0x.... toujours suivant inside uo. son code Hexadecimal
% skill requis : % minimum requis pour faire l'objet
% skill requis pour 100 % chance faire item : le % requis pour avoir 100 % de chance de faire l'item.
Damage min/max : Parfaitement évident.
Vitesse : Vitesse de l'arme.
Range : Portée de l'arme
Protection AR : Protection physique
Protection Feu : Protection Feu
Protection Eau : Protection Eau
Protection Electrique : Protection Electrique
Protection Poison : Protection poison
Flip possible ( ID ) : Autre position possible de l'objet. 0x... ( DOIT EXISTER DANS INSIDE UO )
Composition : 4 feuilles de champignons 0x... <-- ID de l'ingrédient , 2 grains de sel 0x... <-- ID de l'ingrédient .
Attribue Magique : Bonus magique ( + 2 all skills ) , nightsight
Effet : poison -12pv/2 seconde, pendant 50 seconde
Poids : plus l'objet prend de ressource a faire plus il sera lourd.
Couleur : Son hue le cas echeant
Layers : Pour les armes, armure. bijoux, vetements.

Toujours remplir au complet le formulaire. Si une des options n'a pas rapport avec l'objet, mettre N/A dedans.
