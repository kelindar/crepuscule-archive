Alors voilà... C'est pas tout à fait une suggestion d'ajout pour le serveur en tant que tel, mais pour le forum. En commençant à mettre en page mon Background, j'ai ressenti l'affreux manque de l'utilité du BBcode de tableaux. Il n'est de toute évidence pas de base sur le forum de Crépuscule, mais je sais qu'il a moyen de l'ajouter via le panneau d'administration. Je sais pas si vous y avez accès mais, sioui ! je vous propose une solution pour aller avec ladite suggestion =)

table :
BBCode : {TEXT}
HTML :

{TEXT}

td :
BBCode : {TEXT}
HTML : {TEXT}

**td= : **
BBCode : {TEXT}
HTML : {TEXT}

**tr : **
BBCode : {TEXT}
HTML : {TEXT}

C'est tout bonnement esthétique, mais un tableau permet de mieux organiser certaine chose, écrire à droite/gauche d'une image ou encore aligner le texte de façon justifier sur une certaine largeur déterminée. C'est plutôt sympathique pour certaines mises en pages, sans devoir absolument passer par photoshop pour régler ci, et ça.

Alors bon, je suggère... ! =)
