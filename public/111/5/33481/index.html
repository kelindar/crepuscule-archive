viewtopic.php?f=48&t=26586 **Liste des commandes de Crépuscule**

Un X représente un nombre.

.anim X : Permet de faire bouger votre personnage de façon spéciale.
.changelayer : Permet de changer le layer d’un objet par vous-même.
.chantX : Permet de lancer les sorts bardiques sans avoir à passer par le livre.
.chut : Permet de chuchoter une phrase à quelqu’un de relativement près de vous, selon votre compétence en cachette d’ombres.
.coderlivre: Permet de coder un livre selon vos aptitudes en érudition.
.decomove : Permet d’aménager les objets pour mieux décorer.
.decrire "texte": Permet de décrire un objet.
.druideX : Permet de lancer les sorts druidiques sans avoir à passer par le livre.
.emote : Permet de sélectionner des emotes prédéfinies à faire faire à votre personnage.
.faim : Indique votre taux de faim (/20) et votre taux de soif (/20). La commande .soif fait la même chose. Ces deux taux n’ont pas d’influence directe sur votre personnage, mais peuvent influencer votre aptitude en combat et vos chances de réussite au niveau du craft.
.fiche : Permet de consulter la fiche de votre personnage, avec les points d’aptitude, l’âge, la classe, etc. C’est via ce menu que vous placez vos points à chaque niveau.
.guilde : Permet d’afficher ou de cacher votre badge de guilde.
.influence: Permet de voir l'influence globale des guildes.
.masque : Permet d’utiliser votre seconde identité (permanent : il faut refaire la commande pour quitter ce mode). Nous vous demandons de l’utiliser de façon conséquente (par déguisement ou autre).
.mindastraltravel : Commande utilisée par les télépathes pour le voyage astral.
.mindattack : Commande utilisée par les télépathes pour l’attaque mentale.
.mindemotions : Commande utilisée par les télépathes pour faire ressentir leurs émotions.
.mindfollow : Commande utilisée par les télépathes pour suivre la personne de leur choix.
.mindimpressions : Commande utilisée par les télépathes pour transmettre des impressions.
.mindrecall : Commande utilisée par les télépathes pour retourner à leur corps.
.mindsay : Commande utilisée par les télépathes pour parler par la pensée.
.mindsleep : Commande utilisée par les télépathes pour endormir une cible.
.mindtalkadd : Commande utilisée par les télépathes pour établir des contacts mentaux.
.mindtelekinesis : Commande utilisée par les télépathes pour utiliser leur pouvoir de télékynésie.
.montrernom : Permet de cacher / afficher votre nom aux autres joueurs, qui ne le verront pas apparaître dans leur écran et dans le journal si vous le cachez.
.montrermonstres : Commande utilisée pour afficher / cacher les animaux - Monstres - autres.
.noblesse: Permet d'afficher ou de cacher votre tag de noblesse.
.nouveau: Permet d'afficher ou de cacher le nom des PNJ.
.regs: Permet de voir combien de réactifs vous avez dans votre sac.
.renom "texte" : Permet d’affubler un personnage d’un surnom pour le reconnaître, sans quoi il apparaît comme « Inconnu » en jeu ou dans le journal.
.rumeurs : Permet de voir l'influence de chacune des guildes dans chaque domaine. Empire seulement.
.soif : Indique votre taux de faim (/20) et votre taux de soif (/20). La commande .faim fait la même chose. Ces deux taux n’ont pas d’influence directe sur votre personnage, mais peuvent influencer votre aptitude en combat et vos chances de réussite au niveau du craft.
.rumeurs: Permet de voir l'influence de chacune des guildes dans chaque domaine.
.temps: Permet de voir la date et l'heure en jeu.
.tiefling : Commande qui s’utilise seulement par les personnages tieflings pour débloquer leur côté démoniaque et les avantages qui vont avec.
.verrou : Permet de verrouiller un objet pour éviter qu’il ne decay. À réutiliser sur l’objet pour qu’il soit possible de le bouger.
.xp : Indique votre niveau et vos points d’expérience.
