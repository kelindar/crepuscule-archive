Un message de haute importance était posté avec évidence à divers endroits dans les quartiers de l’ordre.

Mes frères, il est temps pour nous tous d’honorer une fois de plus notre engagement envers l’empire et Thaar lui-même. Suite à une décision unanime du conseil des guildes, les troupes mercenaires, impériales ainsi que celles de l’ordre saint, ont pour ordre de faire front au Camp Gitans dans les jours à venir. Soit aujourd’hui (le 16 octobres) ou demain, soyez alerte pour l’éventuel signe qui serra donné afin de regrouper les troupes.

Nous devrons faire route dès le lendemain vers le nord pour prendre d’assaut la forteresse barbare dans les terres nordiques afin de se débarrasser une bonne fois pour toute de la menace.

Reposez vous bien, et prier le très haut dans le temps qu’il vous reste. Nous aurons besoin de toutes vos forces sur le champ d’honneur. Puisse Thaar être avec nous pour ce coup décisif sur les troupes ennemies.

Acolyte, Aerandir Finwë
