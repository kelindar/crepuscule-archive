Désormais, vous n'aurez plus à inscrire sur le forum Reset PA les éventuels changements.

Il suffit de faire .get paresetcount pour vérifier si le nombre de 3 n'est pas atteint. S'il n'est pas atteint, procédez au changement, puis faites .inc paresetcount 1

Les données de tous les Reset PA précédents ont été entrés sur les divers personnages en jeu, le forum devient donc désuet. Seul Azmaïl (1 Reset PA) et Farric (1 Reset PA) n'ont pu être entrés, faute que je puisse me souvenir de leur nom de compte.

Sinon... le forum Reset PA est appelé à disparaître prochainement, sauf s'il y a opposition.
