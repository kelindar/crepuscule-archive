Post by Conteuse Seshat - July 21, 2007 at 5:27 PM

Tous les items de Crépuscule sont susceptibles de pouvoir devenir un objet d'annonce générale.

C'est défini dans les props, dans la catégorie "CrepusculeItem", sous BroadCastMessage

Une fois que le BroadCastMessage est défini, un double clic suffit à faire apparâitre le message en rouge, dans le coin de l'écran, et ce à tous les joueurs.

Post by Conteuse Seshat - July 21, 2007 at 10:25 PM

Vive la commande .towncriers

Vous faites cette commande, puis cliquez sur le petit symbole carré

Vous inscrivez le nombre de temps que la nouvelle doit durer, sous le format :

heures:minutes:secondes
Ex : 3:00:01 pour 3 heures 1 seconde

Ensuite, vous écrivez réplique par réplique ce que les TownCriers doivent dire

À chaque fois que vous pesez sur entrée, c'est comme si vous envoyez le message avec votre Pj. Vous pouvez écrire autant de lignes que vous voulez, et quand vous avez terminé, vous appuyez sur Escape (esc)

Lorsqu'un joueur s'approchera d'un towncrier, peu importe il est situé où, et s'il dit le mot "nouvelle", le Towncrier dira le message programmé, tant que le temps n'est pas écoulé

Voilà
