Les Plans

Légende
Incantion = Série de mots magiques devant être devinée à la suite d'indices récuperés sur des monstres aléatoires (Rares)
[ Item Rare ] = Item Exprès pour le voyage planaire, trouvable à la fin d'un donjon, sur une créature puissante, ect
[Nom-De-Monstre] = Item fait pour le voyage planaire, trouvable sur la créature inscrite dans l'encadré(Le monstre ne drop pas toujours cet item)
[ Ressource] = Objet Courant devant être deviné pour l'incantation
[ Pierre ] = Pierre Précieuse néscéssaire à l'ouverture du passage
Autel d'Incantation = Version enchantée d'un Autel ( Par un enchanteur )
Autel = Création du Bricoleur

Tout les ingrédients doivent être placer sur un autel d'invocation, puis la bonne formule récitée.
