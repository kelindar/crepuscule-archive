Liste des cartes

Post by Conan - May 26, 2010 at 3:28 PM

Voilà donc un début de liste de cartes, pas encore complète, mais c'est surtout pour avoir une liste d'illustrations sur lesquelles on peut déjà commencer à bosser.
Les annotations entre parenthèses sont surtout là pour donner une idée de l'effet de la carte et donc éventuellement de l'illustration qui devra l'accompagner.
Histoire de rester simple pour un premier jet, je me suis limité à trois guildes et une classe par guilde.
Le nom des personnages et des cartes est évidemment générique par soucis de clarté. On ajoutera plus de personnalité au fur et à mesure. ("Raoul Klafonsky, Adepte de Yag'shul" au lieu de "Nécromancien de Yag'shul", par exemple)

Liste des cartes :

Guilde des Ombres :

Personnage :

  • Nécromancien de Yag'shul ( peut convertir ses points de vie en mana, commandement élevé )

Equipement :

  • Miroir des Âmes ( Nécromancien / Objet / diminue le cout des familiers )

Action :

  • Contrat d'assassinat (Guilde des Ombres / Ephémère anti-Gardien)
  • Zombie (Nécromancien / Familier / cout bas )
  • Squelette (Nécromancien / Familier )
  • Golem d'ossement (Nécromancien / Familier / protège son controleur)
  • Murmure de la Crypte (Nécromancien / Éphémère redonnant du mana (?) basé sur la présence de gardiens/familier dans les défausses)
  • Charge cadavérique (Nécromancien / Éphémère boostant l'attaque de ses familiers)

Ordre du Soleil :

Personnage :

  • Paladin de Thaar ( Peut aller chercher une armure dans son deck et la mettre dans sa main )

Equipement :

  • Chapelet Thaarien ( Ordre du Soleil / Objet prévenant les dégats magiques )
  • Bouclier de l'Ordre ( Paladin / Armure )
  • Marteau de l'Ordre ( Paladin / Arme )

Action :

  • Armure étincelante ( Paladin / Ephémère / le score de défense du paladin s'applique également aux dégats magique )
  • Arme consacrée ( Paladin / Ephémère / ignore la défense adverse )
  • Combattant Vertueux ( Paladin / Durable / le paladin peut protéger ses alliés )
  • Soin mineur ( Paladin/Prètre / Ephémère / soin sur une cible )

Confrérie Pourpre :

Personnage :

  • Arcaniste Pourpre ( gagne du mana pour chaque carte défaussée )

Action :

  • Mur de flamme ( Mage / Durable / dégat mineur de feu sur toute cible attaquant le Mage, disparaît après un tour entier )
  • Eclair d'énergie ( Mage / Ephémère / Dégat direct ne pouvant être prévenue )
  • Barbecue ( Mage / Ephémère / Dégat direct sur tout les personnages, familier et gardien en jeu )
  • Bannissement ( Mage / Ephémère / Anti-Familier )
  • Téléportation ( Mage / Ephémère / annule l'attaque en cours )
  • Surcharge Magique ( Mage / Ephémère / Double les dégats infligés par le prochaine action de dégat direct jouée par le Mage )

Neutre :

Equipement ( le tout étant commun, basique ):

  • Glaive
  • Main Gauche
  • Claymore
  • Sceptre de Guerre
  • Bâton d'Invocation
  • Bouclier Rond
  • Armure de plate

Action :

  • Eclair de feu ( Mage/Nécromancien / Ephémère / dégat direct de feu sur une cible )
  • Pot-de-vin (Ephémère, annule les effets d'une carte en jeu pour ce tour)
  • Eloquence (Durable, Diminue le cout en mana des Gardiens)
  • Charisme (Durable, Augmente le Commandement du personnage de 1)

Allié :

  • Soldat Mercenaire ( coût en mana peu élevé )
  • Juriste Impériale ( peut détruire les actions durable adverse )
