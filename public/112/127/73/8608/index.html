Dès la mise à jour il y aura une légère modification pour les changement de classes.

  1. Mettre "ResetAptitude" à True. (Remet les Aptitudes à Zéro)
  2. Mettre "ResetSkillsCap" à True. (Remet les SkillsCaps et les Skills à 20)
  3. Mettre "AjusterStats" à True. (Remet les trois Stats à 20 et place leur Caps selon la race.)
  4. Selectionner la classe souhaitée dans "Classe".

Post by Loopseen - May 12, 2007 at 3:02 AM

Étapes:

1- ResetAptitudes à True (Remet Aptitudes à Zéro)
2- Le Joueur Place rapidement ses aptitudes (Sachant avant de Pager environ comment il les désire.
3- RecalculateSkillsCaps à True (Place Skills Caps selon Aptitudes et descend Skills au besoin)
4- AjusterStats à True(Vu que certaines aptitudes modifient les Stats)
5- Gm place trois stats à la main: "Str", "Dex", "Int". (Le joueur sachant encore une fois d'avance les trois valeurs.)

PS: C'est plus rapide de faire * .set x True * que de chercher dans les props.
PS2: Toujours s'assurer qu'il n'y a pas d'items magiques sur le personnage et que les tiefling sont bien en mode Humain. (C'est chiant mais je ne peux rien y faire...)

Post by Conteuse Seshat - July 14, 2007 at 8:28 PM

Rappel de la procédure :

1- .set classe X
2- .set resetaptitudes true
3- Le joueur replace ses aptitudes
4- .set recalculateskillscaps true
5- .set ajusterstats true
6- Place manuellement les 3 stats : .set rawstr X, .set rawdex X, .set rawint X

Voilà

Si les problèmes suivants surviennent :

- Pas les bonnes aptitudes

Vérifiez si vous avez bien changé la classe (c'est bête, mais c'est ça)

- Le joueur n'arrive pas à mettre ses aptitudes (pas de flèche pour)

Faites le .set resetaptitudes, ça devrait réinitialiser le tout

- Les caps sont à 100 dans des skills non-désiré

Faites le .set recalculateskillscaps true, ça devrait tout arranger

- Les stats sont trop hautes pour les possibilités du personnage

Un petit .set ajusterstats true devrait arranger les choses

Voilà, petit rappel
