Le serveur étant vieux, basé sur RunUO 1.0 RC0 d'il y a 3 ans, a été décompilé par mes soins, corrigé les diverses erreurs du à la décompilation. Les codes sources sont dans le SVN, j'ai recompilé une version sous .Net framework 2.0 pour qu'on puisse utiliser le c# 2.0.
Par la suite on pourrait même le recompiler sous le framework 3.5 pour pouvoir utiliser le c# 3.0.

Donc 2 choses principales possibles maintenant:

  1. Modification des sources de base de RunUo (donc les classes genre Mobile, Item... peuvent être modifiés maintenant)
  2. Utilisation du c# 2.0 et bientôt 3.0 avec toute leur puissance.

Ce sont des petits trucs, mais concrètement, dans le c# 2.0 on a les génériques. Une petite explication ici:

Nouveau dans .NET 2.0 : présentation des « Generics »

Une des principales nouveautés du framework 2.0 de .NET est l’arrivé des « Generics » (Générique en français) qui fait partie de la catégorie des « Collection ». Dans les versions 1.1 et 1.0, pour créer une collection, on pouvait utiliser, entre autre, un ArrayList. Les éléments ajoutés dans un ArrayList sont sauvegardés sous forme d’objet. Les problèmes arrivent quand on ne sait pas exactement ce qui a été ajouté dans cet ArrayList.

Prenons un exemple :

int total = 0;
ArrayList monArrayList = new ArrayList();

monArrayList.Add(25);
monArrayList.Add(5);
foreach (int item in monArrayList)
{
total = total + item;
}

Ce code ne va pas poser de problème, le résultat sera bien de 30.
Maintenant, on va utiliser le code ci-dessous :

int total = 0;
ArrayList monArrayList = new ArrayList();

monArrayList.Add(25);
monArrayList.Add(5);
monArrayList.Add("Bonjour");
foreach (int item in monArrayList)
{
total = total + item;
}

C# étant un language fortement typé, le développeur s’attend en cas d’erreur à un message du compilateur. Or ici, le compilateur ne va rien signaler. En effet, on ajoute dans la liste un objet, 2 int et un string, jusque la rien à signaler. Le problème va se poser à l’éxécution.
Lors de l’ajout des éléments, le compilateur fait un « boxing » d’un int, même chose pour le second, pour le 3ème il fait un « boxing » de string. Lorsque l’on parcourt la liste, un « unboxing » est réalisé qui, dans notre cas sera int, donc les éléments sont transformés en int et donc une exception sera générée lors du passage sur le dernier élément.
Nous allons créer une classe générique qui pourre être utilisée pour n’importe quel type (int, string, float, …)

public class MaClasseGenerique
{
private List _element;

public MyGeneric&#40;&#41;  &#123; this&#46;_element = new List&#40;&#41;; &#125;

public int Count  
&#123;  
    get &#123; return _element&#46;Count; &#125;  
&#125;

public void Add&#40;T nouveau&#41; &#123; this&#46;_element&#46;Add&#40;nouveau&#41;; &#125;

public T GetElement&#40;int i&#41; &#123; return _element&#91;i&#93;; &#125;

}

Que trouve-t-on dans cette classe :

* un nom bien evidemment mais un <T>, qui sera remplacé par le type voulu lors de la création de l’instance  
* un constructeur, qui va créer une list de type <T>  
* une propriété Count qui retournera le nombre d’éléments que compte la liste  
* une méthode d’ajout qui va permettre d’alimenter cette liste  
* une méthode que retourne un élément spécifique de la liste

Utilisation de cette classe :

int i = 0;
int total = 0;
MaClasseGenerique list = new MaClasseGenerique ();

for (int x = 0; x < 10; x++){
list.Add(x);
}

for (i = 0; i < list.Count; i++){
total = total + list.GetElement(i);
}

On va créer une instance de la classe, ici nous allons utiliser des int. Vous constaterez que le a été remplacé par . La première boucle permet d’ajouter quelques éléments à la liste. Dans la classe vous pouvez voir que la méthode Add fait simplement un ajout d’un élément dans une liste mais un élément de type T donc pour nous un int. La seconde boucle permet de parcourir les différents éléments de la liste. Si maintenant, vous utilisez notre classe générique avec des string comme ceci :

int i = 0;
string total = "";
MaClasseGenerique list = new MaClasseGenerique ();

for (int x = 0; x < 10; x++)
{
list.Add(x.ToString());
}

for (i = 0; i < list.Count; i++)
{
total = total + list.GetElement(i);
}

Vous constaterez que le fonctionnement est semblable, c'est-à-dire que notre classe générique fonctionne avec le int, les string mais aussi avec toutes les autres primitives et n’importe quelle class de votre cru.
Voila un très bref descriptif de la puissance des génériques.

Dans le cadre du serveur RunUo par exemple, vous pouvez directement créer des listes fortement typées, grâce aux classe préfaites par microsoft:

List listeJoueurs = new List();
listeJoueurs.Add( ... ); //on ajoute des objets dans la liste comme on faisait avant

foreach(RacePlayerMobile mobile in listeJoueurs)
{
mobile.Frozen = true;
}
