Io,

J'ai ajouté une fonction PrepareCraft() dans le CraftSystem.

Ce qui permet d'ajouter le craft sans devoir à éditer le ficier qui contient tous les crafts (Parfois peut être utile). Ca change rien à priori, vous pouvez faire ça :

public class GraveDiggersShovel : CrepusculeItem
{ ...

    public static void Initialize()  
    {   
        // Ajoute dans le craft (c'est juste une alternative pour faciliter la tâche)  
        CraftSystem&#46;PrepareCraft(typeof(DefTinkering), typeof(GraveDiggersShovel), "Autres",  
            "Pelle des voleurs de tombes", 25&#46;0, 55&#46;0, typeof(IronIngot), "Lingot de fer", 15, "Vous n'avez pas assez de lingots");  
    }

}
