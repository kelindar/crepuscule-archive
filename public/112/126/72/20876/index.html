Au fait Will, voici comment (pas encore sûr à 100%) tu va pouvoir définir qu'un Item est dans un projet de recherche.

public class CryptographicDocuments &#58; CrepusculeItem  
&#123;  
    public static void Initialize&#40;&#41;  
    &#123;   
        Science&#46;RegisterItem&#40;typeof&#40;CryptographicDocuments&#41;, ScienceDomain&#46;Mathematics, "Cryptographie", 10010&#41;;  
    &#125;

    &#46;&#46;&#46;

Où 10010 est un numéro de projet de recherche fondamental (jte montrerai où y a la liste).
Assez simple non? Juste avec cette ligne de code ça va créer un projet de recherche appliquée ^^
