Système d’identification

Réussite de l’identification :
Comme avant, directement lié au skill. L’objet doit être dans le sac.

Affichage de l’identification :
La description de l’objet est conservée (.decrire). Pour le reste, l’image parle d’elle-même !

Processus d’identification :
Chaque caractéristique de l’objet est testée.
Si cette caractéristique est non-nulle, on effectue un jet en fonction de la skill (min 30% pour réussir le jet, max 90%). La caractéristique sera affichée uniquement si le jet est réussi. On peut donc avoir un affichage partiel des propriétés. La valeur attribuée est choisie dans une échelle et peut subir une erreur. C'est-à-dire que par exemple une caractéristique normalement « forte » peut être évaluée à « très forte » ou « moyenne » si celui qui identifie a moins de 80% dans la skill. La probabilité d’erreur est bien sur pondérée par la skill et limitée dans un certain rayon de valeurs proches.

Caractéristiques non reprises :
Les caractéristique non reprises se rapportent surtout à arms lore, je n’ai donc pas toruvé pertinent de les reprendre.
-\tUse remaining
-\tPoison
-\tRésistance
-\tArtefact rarity
-\tLower stat requirement
-\tType de dommage des armes
-\tDurabilité
-\tSkill d’usage (fencing, sword, …)
-\tRayon d’attaque (le range des arc quoi)

Echelles :
Chaque échelle est caractérisée par ses dénominations, leur quantité, la marge entre ses paliers et son erreur admise.
Step = marge entre les paliers
Vmax = nombre max de paliers de différence à l’identification
(int value, double skill, double step, int vmax, int smax)

LuckScale
Uniquement pour la chance qui admet des valeurs plus grandes
Step = 20
Vmax = 2
case 0 : return "Nulle";
case 1 : return "Très Faible";
case 2 : return "Faible";
case 3 : return "Moyenne";
case 4 : return "Forte";
case 5 : return "Très Forte";
case 6 : return "Exceptionnelle";
default : return "Divine";

MagicScale
Pour le CastRecovery et le CastSpeed qui ne prennent normalment que des valeurs entre 1 et 3
Step = 1
Vmax = 1
case 0 : return (type ? "Nul": "Nulle");
case 1 : return "Faible";
case 2 : return (type ? "Moyen" : "Moyenne");
case 3 : return (type ? "Fort" : "Forte");
default : return (type ? "Divin" : "Divine");

BonusScale
Tous les types de bonus qui sont en % en général
Step = 10
Vmax = 2
case 0 : return (type ? "Nul" : "Nulle");
case 1 : return "Très Faible";
case 2 : return "Faible";
case 3 : return (type ? "Moyen" : "Moyenne");
case 4 : return (type ? "Fort" : "Forte");
case 5 : return (type ? "Très Fort" : "Très Forte");
case 6 : return (type ? "Exceptionnel" : "Exceptionnelle");
default : return (type ? "Divin" : "Divine");

StatScale
Pour tout ce qui est bonus stat (str,in,dex,stam,mana,life,…)
Step = 2
Vmax = 1
case 0 : return (type ? "Nul" : "Nulle");
case 1 : return "Faible";
case 2 : return (type ? "Moyen" : "Moyenne");
case 3 : return (type ? "Fort" : "Forte");
case 4 : return (type ? "Très Fort" : "Très Forte");
case 5 : return (type ? "Exceptionnel" : "Exceptionnelle");
default : return (type ? "Divin" : "Divine");
