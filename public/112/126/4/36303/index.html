Voici les astuces pour faire fonctionner vos logiciels favoris avec Crépuscule 2

UOMAP

Ouvrir UOMAP
Cliquez sur l'onglet "Carte"
Choisir "Uo client data files locations"
dans la fenêtre qui s'ouvre vous décochez "Have UOAM locate client data ... etc"
En dessous vous indiquez le chemin direct vers l'emplacement où se trouve installé votre crépuscule 2

exemple : C:\Jeux\Crépuscule 2

Inside Uo

Ouvrir Inside
Cliquez sur l'onglet "Veiw" puis ensuite sur "files Paths " (de toute manière vous n'avez pas le choix)
Une fenêtre s'ouvre avec le nom de tous les dossiers .MUL de crépuscule. Il va vous falloir indiquer dans l'espace vide à coté le chemin où se situe chacun d'eux.

exemple ANIM.MUL C:\Jeux\Crépuscule 2\anim.mul

Pandora

Il faut installer la nouvelle version que vous trouverez (http://code.google.com/p/pandorasbox3/downloads/list) (choisissez la version 3.0.0.5)

Lorsque vous le lancerez la première fois. Il y aura peut-être un message d'erreur :

"The client path has not been found, maybe your registry key is corrupted or is missing, choose a way to fix it :
yes : Pandora will try to search where you installed the client automatically
No: you manually specify the client path"
Vous cliquez sur "No" et ensuite vous allez lui indiquer le chemin pour atteindre le fichier Crépuscule 2

exemple : C:\Jeux\Crépuscule 2

et vous relancez, il se peut qu'il vous demande d'indiquer le chemin plusieurs fois avant de comprendre.
Ensuite si vous n'avez vraiment pas de chance un autre message d'erreur va apparaitre (oui oui ça arrive, ça m'est arrivé)

"Une exception non gérée s'est produite dans votre application. Si vous cliquez sur Continuer, l'application va ignorer cette erreur et essayer de continuer. Si vous cliquez sur quitter, l'application va s'arrêter immédiatement."

Vous arrêtez votre Pandora. Vous allez sur l'îcone de lancement de votre logiciel, faites un clique droit / propriété.
Ensuite vous choisissez l'onglet "Compatibilité"
Regardez dans le bas de la fenêtre et si la case "exécuter ce programme en tant qu'administrateur " est cochée, décochez là. Faites ok.

Normalement votre Pandora fonctionne. Si ce n'est pas le cas .. ça dépasse mes compétences et allez vous plaindre à Kel.
