Bon bon... j'ai vu que certains (dont moi) ont eu par le passé des problèmes à installer Pandora's Box sur Windows Vista (Willy, entre autres)... je vous fait un petit résumé ici :

1- Installer .NET Framework 1.1

Je sais, ça peut paraître con, surtout quand les versions de Vista viennent avec .NET Framework 3.0 ou 3.5.... mais la lignée 2.0 à 3.5 est différente de la 1.1, et les deux sont plus complémentaires que évolutives (elles se complètent)... Vous aurez donc 2 (deux) .NET Framework d'installés.

2- Lancer l'installation de Pandora's Box

Une fois le concept des deux .NET Framework compris... il n'y a plus de problème à l'installation sur Vista (du moins dans mon cas, tout à fonctionné à merveille).

Tout simple, mais quand même à savoir (j'ai passé une bonne demi-heure à travailler comme une folle juste pour installer Pandora's Box et fouiller les forums de RunUO dans la quête d'une réponse ^^)
