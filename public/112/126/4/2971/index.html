( ! ) Coffres d'aides Gms

Post by Ex-Ariakan - October 17, 2005 at 9:33 AM

Voilà, à la location : 117 120 0

Plusieurs coffres furent ajoutés pour aider les Gms :

  • Tous les vêtements craftables par le menu de tailoring.

  • 1000 items de plusieurs ressources. Tous les types de Lingots, tous les types de Leathers, les Cloths, les Boards et les Logs.

Il y a encore plusieurs coffres vides, ceci est simplement si vous avez des choses que vous désirez rajoutés. Ces coffres sont là pour aider à habiller rapidement vos Npcs ainsi que d'avoir des choses rapidement sans avoir à chercher.

Ils sont par contre en .set movable false, donc les Conseillers ne peuvent pas les prendre et si vous leur faites un .dupe, vous devez absolument leur faire un .set movable true pour les utiliser. Je vous demanderais donc de ne jamais déplacer ce qui est dans les coffres actuellement, je les ai placé afin d'avoir une rapidité d'accès aisée
