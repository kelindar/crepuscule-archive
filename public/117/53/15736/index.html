Voici quelques petites idée lors de mon adhésion de se que j,avais parler, il en tien qu'a vous pour décidez si ceci est potable ou non.

Entrainement de l'Armée des Mercenaires

1-Pour commencer, quelques étirements et échauffement afin de ne pas se brisé un muscle ou autre, pendant environ 5 minutes.

2- Entrainement de base : 20 pompes en armure

3- Entrainement de base : 30 redressement assied

4- Entrainement de base : 10 tours à la course du terrain extérieur de l'Armée

5- Quelques exercices de formations, pendant 10 minutes :

Garde à vous, description d'un beau garde à vous :

1- Bien droit, ne fléchissant point.
2- Les bras le long du corp, les mains refermer en poing contre les cuisses.
3- Pied formant un angle de 90 degré.
4- Épaule reculer vers l'arrière.
5- Fixant droit devant et non ailleur.
6- Interdiction de bouger tant que l'ordre de relaxer n'est donner ou le rompé.
7- Le tout doit être fait le plus rapidement possible et si possible en même temps.

Repos, description d'une belle formation repos :

1- Bien droit, ne fléchissant point.
2- Les bras le long du corp, les mains allant joindre les autre derrière le fessier.
3- Les mains doivent être, la droit par dessu la gauche, le pouce droit par dessu le pouce gauche.
4- Épaule reculer vers l'arrière.
5- Fixant droit devant et non ailleur.
6- Interdiction de bouger tant que l'ordre de relaxer n'est pas donner ou le rompé.
7- Le tout doit être fait le plus rapidement possible et si possible en même temps.

Relaxer, description d'une relaxation d'une formation :

1- Bien droit, pouvant fléchire le dos légèrement.
2- Les bras pouvant aller se gratter ou autre.
3- La tête pouvant bouger de même.
4- Les jambes ne doit pas bouger.
5- Interdiction de bouger les jambes tant que l'ordre de rompé n'est donné.

Rompé, description d'un rompage de rang :

1- L'ordre du garde à vous est toujours avant un rompé.
2- Lorsque l'ordre est donné, vous devez avancer de quatre pas, avant de pouvoir bouger comme vous le désirez.
3- Les pas doivent être Gauche, Droite, Gauche, Droite, etc. Les bras suivant le mouvement contraire soit Droite, Gauche, Droite, Gauche, etc.
4- Ensuite, vous pouvez aller vous reposez ou faire toute autre chose

Entrainement de combat :
Un petit tournois entre les membres afin de combattre le plus de personnes. Les combats tous en trois manches chacune. Jusqu'à se qu'il y es
un "gagnant" du petit tournois. À noter, aucun prix, outre que des félicitations est accordé.

Entrainement de formation de combat :

Légende :
Ennemis = X
Allier = O

Combat en duo :
Toujours prendre les combats en équipe. Les deux personnes doivent se positionner dos à dos, pour tuer se qui leur arrive dessu, surveillant
donc les arrières de son partenaire. Frapper le plus possible les plus fort en premier, afin de d'intimider les ennemis.

Combat en trio :
Toujours prendre les combats en équipe et se fier sur ces alliers. Les trois personnes doivent se positionner de facon à couvrire 3 entrés de l'ennemis, donc seul une sera ouverte.

Combat en quatuore :
Toujours bloquer l'accès aux ennemis. En protegeant ses alliers le plus possible. Faites-vous mutuellement confiance et tout se passeras normalement bien. Les deux meilleurs doivent se positionner afin de recevoir trois contre un, comme cela, les moin douer seront comment se débrouiller.

Recrue Desbois
