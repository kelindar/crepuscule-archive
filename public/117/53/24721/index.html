[Affiche] Modèle à suivre pour les rapports

Post by Thalkehr Stornaar, AdM - October 8, 2008 at 2:55 AM

Effectif(s) Présent(s) :
Nommez chaque membre présent avec leur grade. Citez le responsable de l'opération.

Criminel(s) :
Donnez tous les détails qui vous passent par la tête. Nom, race, guilde, description physique.

Lieu(x) :
Nommez l'endroit, s'il est peu connu, décrivez son emplacement.

Témoin(s) :
Nommez les témoins avec une rapide description, incluant la race et la guilde (avec son rang, si possible).

Chef(s) d'Accusation :
Citez les articles enfreints.

Sanction(s) :
Décrivez les sanctions et citez l'article qui vous permet de le faire.

Rapport Détaillé :
Décrivez tous les détails que vous avez été en mesure de retenir. Rien ne doit être laissé au hazard.
