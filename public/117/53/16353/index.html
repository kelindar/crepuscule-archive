Salut les gars ( et les garces ^^ ) Une petite propostion tentez pour vos missives aussi courtes soient t'elles d'écrire dans une couleur lisible, certains semblent apprécier le vert mais cela me file mal aux yeux ( ils / elles se reconnaitront ). Aussi pour une meilleure apparence sur le forum écrivez entre [ / quote ] ( sans espace ) cela donne beaucoup mieux.

Un exemple :

Monsieur,

Pour vous signaler que Mr T est le meilleur.

Moi

Avec la balise [ quote] et la balise [ i] ( qui sont accessible dans les barres de menu du dessus. ) vous pouvez donner une meilleure apparence a vos missives.

Monsieur,

Pour vous signaler que Mr T est le meilleur.

Moi

J'espere que cela vous servira.. ^^
