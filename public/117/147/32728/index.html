Comment bien poster dans cette section!

Post by Anteïa Meserole, Adm - February 4, 2010 at 8:17 PM

Bien!

1- Le titre :

Le titre doit-être compréhensible et dire le but du poste. D'inscrire :

[Enquête] Inscrire ici le nom de la personne/groupe sur laquelle se porte l'enquête
[Rapport de ronde] Inscrire ici le nom du mercenaire
Inscrire ici le nom de la personne/ ou de l'évènement sur qui porte le dossier
[Rapport d'infraction] Inscrire ici le nom du suspect, de l'endroit, ou du plaignant

2- Le contenue :

Le jolie post-it indiquer : Modèles de rapports Vous indiquent exactement ce qu'il faut faire! et le format est également important pour une meilleur lisibilité.

Les rapports de rondes d'un mercenaire doivent être poster l'un à la suite de l'autre dans le même poste. Les dossier relatif à la même personne doit toujours être dans le même poste! Éviter d'embourber inutilement le forum!!

Des questions? Hésiter pas a me contacter!
