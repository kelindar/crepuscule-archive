Bonjour, je vous presente Core Uo, un programme permettant d'avoir plusieurs shards et des mises à jours automatiques de chaque shard, dans cette nouvelle version, rien de nouveau, mais la correction de nombreux bugs.

Procédure d’installation
\t

1- Téléchargez le framework via ce lien http://download.microsoft.com/download/ ... tnetfx.exe
2- Téléchargez core Uo via ce lien : http://www.darconet.be/coreuo/core_uo.zip
3- Installez CoreUO dans le répertoire d’Ultima Online

Procédure d’utilisation

Afin d’installer un serveur sur votre ordinateur, vous devez tout d’abord installer ce serveur de façon à le rendre disponible pour CoreUO. Pour ce faire, récupérez les fichiers du serveur via Internet puis, s’Il y a lieu, installez le programme sur votre ordinateur (peu importe l’emplacement, dézippez si le fichier est un .zip/.rar). Allez ensuite dans votre dossier « Shards » précédemment créé et faites y un nouveau dossier nommé selon le serveur que vous installez. Par exemple, le dossier se nommera Crépuscule si vous êtes en train d’installer Crépuscule. Copiez ensuite les fichiers du serveur dans ce dossier en question.

Pour changer de serveur sur votre ordinateur, lancez tout simplement le programme. Choisissez ensuite le serveur que vous désirez utiliser puis cliquez sur Installer. Si vous avez déjà un autre serveur d’installé, cliquez sur Effacer puis installez le nouveau serveur.

Pour jouer à Ultima Online sur le serveur choisit, utilisez la manière décrite sur le site Internet de ce serveur pour lancer le jeu.

Le dossier Backup contient les fichiers originaux d’Ultima Online.
