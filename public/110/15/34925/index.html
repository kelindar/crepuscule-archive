Mise à jour sur le temps pour recevoir le XP

Post by Nimue - July 26, 2010 at 6:28 AM

Chers joueurs,

Dans le but de rendre le jeu plus "amical" nous avons décidé de réduire le temps qu'il faut pour obtenir les points d'expérience. Sans vous donner le calcul exact, vous allez tous remarquer une grande différence qui vous fera surement plaisirs. La limite de points d'expérience reste toujours cependant. Si cela ne vous fait pas plaisir... Bien vous être anormal ou saoul. ;-)

Bref si vous avez une cote de 4, vous ferez vos XP plus rapidement mais vous aurez toujours une limite de 4 XP par jour pour votre personnage.

Amusez-vous!

Nimue
