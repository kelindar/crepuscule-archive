Coucou les gens,

Bon bien nous voila avec un nouvel host, cela nous aura pris deux heures au total ( au lieu d'un délai de 48h prévu ) mais vous pouvez vous amusez maintenant, il est possible que certains posts (Lag de 2h) aient disparu, c'était le prix à payer ^^

Il est cependant possible que vous ayez a attendre pour voir tous ce message, c'est un délai classique de 48h. Si l'un de vos amis vous dit que cela ne fonctionne pas pour lui, communiquez lui cela :

  1. Démarrer
  2. Executer ( sous vista : touche windows + R en même temps )
  3. cmd
  4. Ipconfig /flushdns
  5. Ipconfig /registerdns
  6. CTRL + F5 ( en même temps ) sur la page du forum de crépuscule de votre navigateur.

Puis qu'il réessaye...

Profitez bien de votre nouvel espace de jeu !
