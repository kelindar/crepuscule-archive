Post by Karthanis Tyr - December 29, 2008 at 6:24 AM

Ultima Online sur un Mac

Disclaimer: ce howto comporte des instructions pour plusieurs logiciels. Seules celles qui concernent Wine sont précises car c'est la solution que j'ai employée. Les autres sont basées sur des expériences passées et de l'intuition. Cependant, je suis quasiment certain qu'elles sont justes. Et puis ce sont des interfaces graphiques, la chance
I. Pré-requis
I bis. Installation de Wine ou assimilé
II. Installation de Ultima Online
III. Installation du patch Crépuscule
IV. Jouer

I. Pré-requis
[:ig9g43ec]Macintosh muni d'une puce Intel (ne fonctionne pas avec les puces PowerPC)[/:m:ig9g43ec]
[:ig9g43ec]Wine ou Darwine ou Crossover Mac ou Crossover Games for Mac. Tous ces logiciels sont basés sur la technologie Wine.[/:m:ig9g43ec]
[:ig9g43ec]La dernière version de X11 pour Quartz Extreme: http://xquartz.macosforge.org/trac/wiki/X112.3.1 .[/:m:ig9g43ec]
[:ig9g43ec]Un peu de persévérance[/:m:ig9g43ec][/list:u:ig9g43ec]

I bis. Installation de Wine ou assimilé
Si vous possédez déja l'un des logiciels sus-cités, passez cette étape.

Procurez vous, au choix:
[*:ig9g43ec]Wine: http://prdownloads.sourceforge.net/wine ... 11.tar.bz2
Il vous faudra alors le compiler et l'installer. Pour compiler, vous avez besoin des Developer Tools d'Apple. Vous aurez besoin d'un compte ADC pour les télécharger (1 Go)

http://developer.apple.com/technology/xcode.html (première option)

Vous pouvez alors compiler et installer. Lancez le Terminal (Applications > Utilitaires > Terminal) et faites cd ~/Downloads/wine-1&#46;1&#46;11 puis &#46;/configure && make depend && make et enfin ```
sudo make install

[*:ig9g43ec]<span style="color:#FFFF00">Darwine</span>: <!-- m --><a class="postlink" href="http://www.kronenberg.org/darwine/">http://www.kronenberg.org/darwine/</a><!-- m --> (prenez 1.1.9 unstable)  
Ce logiciel s'installe comme un logiciel Mac OS X.[/*:m:ig9g43ec]  
[*:ig9g43ec]<span style="color:#FFFF00">Crossover Mac</span> (payant) ou <span style="color:#FFFF00">Crossover Games for Mac</span> (payant): <!-- m --><a class="postlink" href="http://www.codeweavers.com/products/cxmac/">http://www.codeweavers.com/products/cxmac/</a><!-- m --> ou <!-- m --><a class="postlink" href="http://www.codeweavers.com/products/cxgames/">http://www.codeweavers.com/products/cxgames/</a><!-- m --> Installez ce logiciel comme un logiciel Mac OS X[/*:m:ig9g43ec][/list:u:ig9g43ec]

<span style="font-size:150%">**II. Installation de Ultima Online**</span>

Selon votre logiciel:  
[*:ig9g43ec]<span style="color:#FFFF00">Wine</span>: Placez tout d'abord l'exe d'install de UO sur votre bureau puis faites ```  
cd ~/Desktop

Puis ensuite lancez l'exe avec wine uoml_setup&#46;exe Choisissez C:\uo comme dossier d'install et terminez la procédure d'installation normalement. Maintenant, il faut patcher jusqu'en v5.0.2b.```
wine "C:\uo\uo.exe"

[*:ig9g43ec]<span style="color:#FFFF00">Darwine</span>: Lancez uoml_setup.exe avec Darwine (Pomme+O), choisissez C:\\uo comme dossier d'install et terminez la procédure d'installation normalement. Maintenant, il faut patcher jusqu'en v5.0.2b. Lancez uo.exe de la même façon. N'oubliez pas d'appuyer deux fois sur "Cancel" le moment venu.[/*:m:ig9g43ec]  
[*:ig9g43ec]<span style="color:#FFFF00">Crossover Mac</span> (payant) ou <span style="color:#FFFF00">Crossover Games for Mac</span> (payant): Lancez uoml_setup avec Crossover Mac ou Crossover Games for Mac. Choisissez C:\\uo comme dossier d'install et terminez la procédure d'installation normalement. Maintenant, il faut patcher jusqu'en v5.0.2b. Lancez uo.exe de la même façon. N'oubliez pas d'appuyer deux fois sur "Cancel" le moment venu.[/*:m:ig9g43ec][/list:u:ig9g43ec]

<span style="font-size:150%">**III. Installation du patch Crépuscule**</span>  
Selon votre logiciel:  
[*:ig9g43ec]<span style="color:#FFFF00">Wine</span>: Placez le patch Crépuscule sur votre bureau. cd ~/Desktop  
wine Crepuscule&#46;exe  
Au cours de l'installation, il se plaindra de l'absence de .NET Framework 2.0.  
![](http&#58;//www&#46;karthanis&#46;net/upload_images/crep/dotnet&#46;png)

Poursuivez, et vous rencontrerez cette erreur:  
![](http&#58;//www&#46;karthanis&#46;net/upload_images/crep/error&#46;png)

Appuyez sur "Répéter" et l'installation continuera sur le chargement des données de Crépuscule. Vérifiez que le chemin d'installation est bien celui que vous avez choisi pour UO.[/*:m:ig9g43ec]  
[*:ig9g43ec]<span style="color:#FFFF00">Les autres logiciels</span>: Ouvrez Crepuscule.exe avec le logiciel choisi. Les erreurs rencontrées risquent d'être les mêmes.[/*:m:ig9g43ec][/list:u:ig9g43ec]

<span style="font-size:150%">**IV. Jouer**</span>  
Faudrait pas que tout ça n'ait servi à rien ![](/assets/smilies/Wink.gif)   
Selon votre logiciel:  
[*:ig9g43ec]<span style="color:#FFFF00">Wine</span>: Si vous avez bien mis C:\\uo comme chemin d'install cd ~/&#46;wine/drive_c/uo/  
wine Crepuscule&#46;exe[/*:m:ig9g43ec]  
[*:ig9g43ec]<span style="color:#FFFF00">Darwine</span>: lancez Crepuscule.exe avec Darwine (Pomme+O)[/*:m:ig9g43ec]  
[*:ig9g43ec]<span style="color:#FFFF00">Crossover Mac</span> (payant) ou <span style="color:#FFFF00">Crossover Games for Mac</span> (payant): Ces deux logiciels ont l'amabilité de créer des simili-applications pour Mac OS X. Normalement, vous devriez trouver un Crepuscule.app dans votre dossier d'applications (suivez les instructions), ou dans le menu Applications de Crossover.[/*:m:ig9g43ec][/list:u:ig9g43ec]

Enjoy!
