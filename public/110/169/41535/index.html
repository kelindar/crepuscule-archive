Pour ceux qui connaissent bien le HTML, le BBCode est facile d'utilisation. Voici donc un bref tutoriel pour les autres.

Il y a déjà un bref tutoriel pour les fonctions les plus utilisés: faq.php?mode=bbcode
Voici pour les autres:Flash: ```
[Flash=largeur,hauteur]http://lien[/Flash]


Utilisé pour mettre directement une animation Flash dans un message.HRP: ```  
&#91;HRP&#93;Texte&#91;/HRP&#93;

Utilisé pour mettre une note HRP dans un forum RP. À utiliser avec modération!

Exemple:

&#91;hrp&#93;Ceci est une note HRP&#91;/hrp&#93;

Ceci est une note HRP
Missive: ```
[Missive=Texte (Optionnel)]Texte[/Missive]

Utilisé pour représenter une missive RP.


Exemple:

[missive=pour Albert]Ceci est une missive pour Albert.[/missive]

Ceci est une missive pour Albert.Note: ```  
&#91;Note&#93;Texte&#91;/Note&#93;

Utilisé pour représenter une note.

Exemple:

&#91;note&#93;Ceci est une note&#91;/note&#93;

Ceci est une note
Affiche: ```
[affiche]Texte[/affiche]

Utilisé pour représenter une affiche.


Exemple:

[affiche]Ceci est une affiche.[/affiche]

Ceci est une affiche.Center: ```  
&#91;center&#93;Texte&#91;/center&#93;

Utilisé pour centrer du texte. Peut aussi être utilisé avec certaines autres balises pour centrer à l'intérieur.

Exemple:

&#91;center&#93;Ceci est du texte centré&#46;&#91;/center&#93;

Ceci est du texte centré.
Point: ```
[p]Texte[/p]

Utilisé pour mettre un point avant du texte sans devoir faire une liste.


Exemple:  
&#91;p&#93;Texte avec un point&#46;&#91;/p&#93;  
Texte sans point&#46;  
&#91;p&#93;Autre texte avec un point&#46;&#91;/p&#93;  
Texte avec un point.  
Texte sans point.  
Autre texte avec un point.

Table:

&#91;table=Largeur de la bordure&#93;Balises tr et td&#91;/table&#93;  
&#91;tr&#93;Texte&#91;/tr&#93; (Lignes)  
&#91;td=Largeur en nombre de cases (Optionnel)&#93;Texte&#91;/td&#93; (Colonnes dans une ligne)  
Permet de créer des tableau. Assez complexe!
