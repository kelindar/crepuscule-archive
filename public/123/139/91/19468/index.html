Restructuration Universtié

1. Public visée

1.1 Les jeunes
Un des publics cibles de l'université est les jeunes, ils faudra donc pour eux créé une atmosphère acceuillant, pour ne pas les répugner de l'école et de toutes formes d'éducation. Il faudra aussi engagée du personnel compétent, ayant patience, sens de la discipline et aimant les enfants. Un prètre de l'ordre pourrais aussi parfaire leurs éducation religieuse.

1.2 Les Adolescents
Le deuxième publics que je cibles sont les jeune adultes. Ceux dans leurs choix de carrière est encore incertains. Nous pourrions leurs offrir des cours se reliant à divers emploie que l'adolescent pourrait un jour décidé de faire. Ce programme comporterais aussi des stages, pour la plupart dans des guildes pour l'encadrement. Par exemple si le cours est technique de soin animalié, nous pourions pendant une période de deux semaine, envoyé un jeune parfaire son éducation au cercle de pierre.

1.3 Les adultes
Chez les adultes, il y à deux catégories: Ceux qui veulent parfaire leurs connaissance dans des domaines particulier, la botanique, la géographie, l'historie et ceux qui n'ayant pas eu d'éducation étant jeune, désire apprendre le néssésaire (lire, écrire , compter).

2. Les Cours

2.1 Les cours pour les jeunes
-Le francais (lecture écriture et orale)
-Les mathématiques
-L'histoire
-La géographie
-Un cours avez des activité physique
-Initiation au préceptes de thaar (données par un prêtre)

2.2 Cours pour les adolescent
-L'alchimie
-La forge
-La menuiserie
-Le bricolage
-Le soin animalier
-La médecine
-Le dressage
-Initiation à la magie (donnée par la confrérie)
-Tecniques d'archivages et de recherches
-etc...

2.3 Cours pour les adultes
-Géographie
-Francais
-Autre langue
-Histoire
-Mathématique
-Connaisance des animaux
-Connaisances des armes
-Anatomie de l'homme
-Cours de théatre(avec les gitans)
-Cours de musiques (avec les gitans)
-etc

3. Publicité et tarification

3.1 Tarification

3.1a Pour les jeunes
Selon moi l'éducation pour les jeunes de moins de 12 ans devrais être gratuite voir obligatorie.

3.1b Pour les adolescent
100 écus de bases par cours plus des supléments dépendant du matériel requis pour le cours. D'autre tarifs suplémentaire pourront être éxigés par le groupe qui auront le jeune pour stagiaire. Une caisse d'aide pour les jeunes en difficultés pourra être faites.

3.1c Pour les adultes
100 écus pour les cours de bases. De 500 à 1000 écus pour les cours avancées. Une caisse d'aide pour les cours de bases seulement pourra être formée.

3.2 Publicité
-distribution de bourse d'études
-Encouragement d'inscrire l'enfant à base age
-Publicité dans les journaux
-Entretien privé avec le professeur, pour voir si le cours lui convient
-L'élève aura jusqu'au deuxième cours pour payer, s'il n'aime pas ce qu'il voit après un, il pourra ce désincrire.

R.D.A Aniya
