Post by Cyriel S. Selaquii, Adc - March 22, 2012 at 4:20 AM

Monsieur Dusyel,

Les prix ont été calculés afin d'assurer 1500 écus de profit à un alchimiste qui achète tous ses ingrédients.

Donc pour une teinture dont le prix est de 3000 écus selon les chartes officielles, il faudrait charger 1500 écus si le consommateur fournit tous les ingrédients.

Pour une teinture valant 10000 écus selon la charte, 1500 écus si il fournit tous les ingrédients.
