Bonjour à tous chères consoeurs et chers confrères.

Ce message se veut à l'issue de quelques discussions concernant notre entrepôt. Je pense que nous devons débuté un débat qui amènera une note positive pour ce qui contiendra notre entrepôt. Ce que je pense que nous devrions faire personnellement :

1- Une liste de tous les items que nous achetons. Combien achèterons-nous ce que les ressources naturelles de la Horde Sanglantes ou encore les divers objets des autres artisans.

2- Établir un maximum d'items dans certains cas. Pour les ressources naturelles, ce maximum devrait être très élevé évidemment !

3- Mettre à jour le nombre d'objets dans nos caisses régulièrement.

Donc un simple exemple pour deux types de chapeau en couture :

Bandana :

Prix d'achat = 15 pièces d'or
En réserve : 10/15 ( 15 serait le maximum ici )

Chapeau de paille :

Prix d'achat = 18 pièces d'or
En réserve : 5/9 ( 9 serait le maximum ici )

Je rappelle que rien de ceci n'est officiel, mais une suggestion de possibilité pour l'entreposage.

Signé soigneusement : Cirdan Sirois, Colporte
