Comment faire les rapports

Post by Rufus Flaron, ind - January 19, 2008 at 6:05 AM

Chers collègues,

Le Baron d'Orbrillant m'a demandé de vous construire un petit guide pour bâtir vos rapports de vente. Tout d'abord, je vous rappelle que selon les règles, vous devez rapporter à la guilde toutes les ventes que vous effectuez. Pour celles que vous faites pour des guildes, 10% de vos profits doivent revenir à l'Association via le coffre de dépôts.

Voici le canvas de base d'un rapport de vente annuel.

BILAN (MOIS (IRL))

Sous-total des ventes personnelles: X écus
Sous-total des ventes de guilde: X écus
Ventes totales: X écus
Somme dûe à l'Association: X écus

Acheteurs
-Nom de l'acheteur (X écus en tout)
-etc.

Dossiers effectués cette année-ci
exemple:

  • Embauchement de Julius Mesiter au poste de Colporte
    etc.

Dans la section dossier, on écrit les réponses aux missives, les dossiers menés à bien, les tâches qu'on a réalisées, etc. La vente de permis est également inclue dans les dossiers. N'oubliez pas d'inscrire le noms de tous ceux qui vous ont acheté et le montant total de leurs achats.

Ce n'est pas plus compliqué que cela pour le bilan annuel.

Voici maintenant pour le bilan individuel (un bilan par commande):

BILAN DE COMMANDE

Acheteur: Nom de l'acheteur
Articles achetés:
Article, prix, quantité, total
Article, prix, quantité, total
Ex.:
3 katanas en sanguine 1200 écus/chq pour un total de 3600 écus
Sous-total: X écus
Rabais accordé: %
Total: X écus
Somme due à l'Association (si l'acheteur est une guilde):

Voilà.

-Erik
