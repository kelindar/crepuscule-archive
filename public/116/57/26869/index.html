La langue des arcannes.

Après avoir longuement regardé des mages, sorcier et druide ainsi qu’avoir entendu parler des nécromanciens je me suis mis à m’intéresser d’avantage au ‘’formule’’ ou la langue des arcannes. J’en suis venu à là conclusion qu’il existe une quantité infinie de sortilège.

Voici quelques exemples ainsi que quelques observations :

Un lanceur de sort prononce dans une formule le mot (AN). Cela signifie automatiquement que le sort qui sera lancé sera un sort de dissipation.

-(AN) signifiant ; Dissipation, annulation, Dispersion...
-(BET) Signifiant ; Petit
-(CORP) Signifiant ; La Mort
-(DES) Signifiant ; Diminution, réduction, baisse, malus…
-(EX) Signifiant ; Libération, libérer.
-(FLAM) signifiant ; Le feu
-(GRAV) signifiant ; Champ, zone, terrain, lieu, domaine…
-(HUR) signifiant ; Le vent.
-(IN) signifiant ; Faire, créé, causer, administre…
-(JUX) signifiant ; Tort, mal, endommager, abîmer, nuire, danger, trappe…
-(KAL) signifiant ; Invoquer, convoquer, appeler, demander…
-(LOR) signifiant ; La lumière
-(MANI) signifiant ; La vie ou le soin.
-(NOX) Signifiant ; Le Poison
-(ORT) Signifiant ; La magie, magique…
-(POR) Signifiant ; Mouvement, déplacement, mobilisions…
-(QUAS) Signifiant ; Hallucination. Illusion…
-(REL) Signifiant ; Changer, changement…
-(SANCT) Signifiant ; Protéger, protection…
-(TYM) Signifiant ; Le temps
-(UUS) Signifiant ; Lever, relever…
-(VAS) Signifiant ; Grand, Super, énorme…
-(WIS) Signifiant ; Connaissance, connaître, savoir…
-(XEN) Signifiant ; Une Créature…
-(YLEM) Signifiant ; Affaire, question, points, matière…
-(ZU) Signifiant ; Le sommeille

Quelques exemple pour mètre le tout en évidence :
Vas Flam ; Super Feu
Kal Vas Flam ; Invoquer super feu
In Nox ; Créé Poison (administrer poison)
In Lor ; Créé Lumière

Et ainsi de suite…

Je me demande si les sorts ne seraient pas possible d’être créé. Certes cela demandera plus de temps, ceci étant qu’une observation suivie de quelques recherches mineures.

Mais il n’en reste qu’il est pratique de bien les connaître pour différencier les types de magies que le jeteur de sort utilise, ex : un sorcier prononce les mots ‘’In Nox’’, une personne averti saura qu’il s’agira de poison donc pourra préparer son sort d’antipoison…
